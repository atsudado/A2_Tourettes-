School Assignment • JavaScript Platformer

Tactic

A rage-bait style platformer inspired by tricky games, designed to raise awareness about Tourette syndrome and tics.

Controls ← / → Move ↑ Jump R Restart level

Awareness message

Tourette syndrome is a neurological condition involving tics: sudden, repeated movements or vocal sounds. The game mechanics are metaphors for how tics can feel unpredictable, triggered by situations, or delayed.

Disclaimer

This is a student awareness game, not a medical tool. Tourette syndrome affects people differently, and the game is meant to encourage empathy and understanding.
